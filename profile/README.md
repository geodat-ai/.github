# Geodat AI Ltd

Geodat AI develops geospatial data science, analytics, and AI-driven platforms for understanding and improving spatial systems.

Our work focuses on:

- digital cartography
- geospatial analytics and modelling
- public transport accessibility and mobility analysis
- spatial data infrastructure
- AI-assisted geospatial data processing
- interactive web mapping and spatial applications

## Platform

The Geodat AI platform is built around:

- containerised services
- cloud infrastructure on Microsoft Azure
- geospatial databases using PostgreSQL and PostGIS
- data science workflows in R and Python
- APIs and microservices written in Go and Python

## Key Technologies

- Go
- Python
- R
- PostgreSQL / PostGIS
- Docker containers
- Azure Container Apps
- Azure AI Services
